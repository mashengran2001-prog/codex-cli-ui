# Nebula 功能对照

本项目以 `Kuddev/nebula` 提交 `8afef65b1ebf29bdf99816b97f129aa52a102a24`（2026-08-18 获取）作为行为对照。Nebula 使用 GPL-3.0；本项目只分析公开功能和交互，不复制其 Rust 源码、图片或其他 GPL 资产。

## 当前覆盖

| 能力 | 状态 | 本项目实现 |
| --- | --- | --- |
| 常驻终端与标签恢复 | 已实现 | Electron 主进程管理 ConPTY，隐藏窗口不断开，保存并恢复标签元数据与终端回放 |
| 标签、分屏与拖拽停靠 | 已实现 | 标签排序、中键关闭、四分屏、窗格缓存、拖拽停靠 |
| Shell 与 CLI 启动 | 已实现 | PowerShell、CMD、Git Bash、WSL、SSH；Codex、Claude Code、Gemini、OpenCode、DeepSeek Harness 和任意自定义命令 |
| AI CLI 活动同步 | 已实现 | Codex `config.toml/notify`、Claude hooks、链式配置保护、自动修复和点击聚焦 |
| 终端日常交互 | 已实现 | 选中复制、右键复制/粘贴、搜索、缩放、链接、行内图片、本地文件安全拖入 |
| 命令面板 | 已实现 | 分组搜索、最近使用、终端切换、分屏、工作区、SSH 与设置动作 |
| 文件与开发工具 | 已实现 | Files、Git、Markdown/GFM/KaTeX、JSON/文本预览 |
| SSH 与 SFTP | 已实现 | 系统 OpenSSH、ssh config 导入、连接测试、交互终端和基础 SFTP 操作 |
| 外观与交互设置 | 已实现 | 七套主题、背景图片、透明度、模糊、光标、面板宽度、补全、Powerline、三档界面密度 |
| 中英文界面 | 已实现 | 跟随系统、简体中文、English；产品术语按使用场景编写 |

## 部分覆盖

| 能力 | 当前限制 |
| --- | --- |
| 崩溃恢复 | 有启动跟踪、恢复隔离和标签快照；尚无 Nebula 的完整诊断界面与输入延迟探针 |
| SSH 高级能力 | 系统 OpenSSH 可继承用户配置；应用内尚无完整代理、跳板、多种认证和 keepalive 设置页 |
| WSL | 能发现并启动发行版；系统目录选择器中尚无专用 WSL 快捷入口 |
| 快捷键 | 已实现可录制自定义键位页（命令面板、新终端、分屏、全局快速终端、打开设置，可一键恢复默认）；尚无分组可搜索的键位列表与冲突检测 |

## 暂缓项目

- 加密工作区导出、恢复预览、冲突处理和回滚。
- 应用内更新检查与发布通道。
- 启动目录、常用目录和目录跳转面板。
- 独立图片查看器与系统字体枚举。
- DeepSeek Harness 的完整插件管理和协议仍在变化的高级设置。

这些项目不适合通过移植 Nebula 源码完成。后续应按本项目的 Provider、Electron IPC 和 React 组件边界独立实现，并为配置迁移和恢复流程增加专门测试。
