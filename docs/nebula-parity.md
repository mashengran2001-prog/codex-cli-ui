# Nebula 功能对照

本项目以 `Kuddev/nebula` 提交 `74f19d8`（v1.2.0，2026-08-21 获取）作为行为对照。Nebula 使用 GPL-3.0；本项目只分析公开功能和交互，不复制其 Rust 源码、图片或其他 GPL 资产。

## 当前覆盖

| 能力 | 状态 | 本项目实现 |
| --- | --- | --- |
| 常驻终端与标签恢复 | 已实现 | Electron 主进程管理 ConPTY，隐藏窗口不断开，保存并恢复标签元数据与终端回放 |
| 标签、分屏与拖拽停靠 | 已实现 | 标签排序、中键关闭、四分屏、窗格缓存、拖拽停靠 |
| Shell 与 CLI 启动 | 已实现 | PowerShell、CMD、Git Bash、WSL、SSH；Codex、Claude Code、Gemini、OpenCode、DeepSeek Harness 和任意自定义命令 |
| AI CLI 活动同步 | 已实现 | Codex `config.toml/notify`、Claude hooks、链式配置保护、自动修复和点击聚焦 |
| 终端日常交互 | 已实现 | 选中复制、右键复制/粘贴、搜索、缩放、链接、行内图片、本地文件安全拖入 |
| 剪贴板截图粘贴 | 已实现 | 剪贴板无文本但有图片时写入临时 PNG，并粘贴带引号的本地路径到终端；SSH 会话通过 SFTP 上传到远端 /tmp 后粘贴远端路径 |
| 命令面板 | 已实现 | 分组搜索、最近使用、终端切换、分屏、工作区、SSH 与设置动作 |
| 文件与开发工具 | 已实现 | Files、Git、Markdown/GFM/KaTeX、JSON/文本预览；文档内本地图片经 IPC 转 data URI 展示，远程图片直连加载，图片加载失败显示占位 |
| Git 仓库兼容性 | 已实现 | git 命令加 `-c safe.directory=*`，修复 WSL 或其他用户所有仓库显示空白 Git 面板的问题 |
| SSH 与 SFTP | 已实现 | 系统 OpenSSH、ssh config 导入、连接测试、交互终端和基础 SFTP 操作；SSH 会话退出后 pane 工具栏与侧栏标签出现“重试 SSH 连接”，一键重建会话；活动 SSH pane 时文件面板自动切换为 SFTP |
| 外观与交互设置 | 已实现 | 七套主题、背景图片、透明度、模糊、光标、可配置字体族（含中文回退链）、面板宽度、补全、Powerline、三档界面密度 |
| 自定义颜色取色盘 | 已实现 | 背景色与界面强调色各配一套 HSV 连续取色器（饱和度/明度取色面 + 色相条），终端背景与强调色实时预览 |
| 标签页颜色标记 | 已实现 | 右键标签选 7 色标记或清除，localStorage 持久化，顶栏与侧栏均显示色条 |
| 标签页重命名与导出 | 已实现 | 右键标签重命名；导出当前标签会话为文本文件（保存对话框，缓冲区内容写入 UTF-8） |
| 退出码与失败状态 | 已实现 | 主进程捕获真实退出码随 exit 事件下发；终端内显示 `process exited (code N)`，非零退出时标签出现失败图标与退出码文案，托盘菜单显示“失败” |
| 新建标签位置 | 已实现 | 设置项可把新标签放在当前标签之后或追加到末尾，随设置持久化 |
| 标签栏位置 | 已实现 | 设置项可选顶部 / 侧边 / 顶部 + 侧边，切换即时生效 |
| 托盘 agent 提醒 | 已实现 | 后台 AI CLI 需要处理时托盘切换为琥珀色提醒图标，点击托盘聚焦对应终端；图标为程序生成的几何图形 |
| 托盘 agent 菜单 | 已实现 | 托盘菜单实时列出所有终端（等待输入/运行中/已退出/空闲），点击直达对应窗格 |
| 文本查看器行号 | 已实现 | 非 Markdown 文件按行渲染并显示行号，长行保留横向滚动 |
| 命令补全 | 已实现 | 内联建议与弹窗候选两种样式；补全对 WSL 路径使用超时保护的只读目录扫描，避免冷启动挂起 |
| 终端铃声模式 | 已实现 | 关 / 仅闪烁 / 仅声音 / 闪烁 + 声音 四档，BEL 节流 1.5 秒 |
| 窗口内代理 | 已实现 | 设置页可配置代理地址与绕过列表，仅注入本应用启动的终端/CLI 子进程环境，不影响浏览器与其他应用；留空时主动清除代理变量 |
| 中英文界面 | 已实现 | 跟随系统、简体中文、English；产品术语按使用场景编写 |
| AI 会话跨重启恢复与分叉 | 已实现 | 恢复纯 Shell 标签时按快照注入 `codex resume <id>` / `claude --resume <id>`；右键运行中的 AI 标签可“继续上次 AI 会话”或“分叉 AI 会话”，设置页可关闭自动接续 |

## 部分覆盖

| 能力 | 当前限制 |
| --- | --- |
| 崩溃恢复 | 有启动跟踪、恢复隔离和标签快照；尚无 Nebula 的完整诊断界面与输入延迟探针 |
| SSH 高级能力 | 系统 OpenSSH 可继承用户配置；应用内尚无完整代理、跳板、多种认证和 keepalive 设置页 |
| WSL | 能发现并启动发行版、文件面板跟随 WSL 路径、命令补全走 WSL 目录扫描；系统目录选择器中尚无专用 WSL 快捷入口 |
| 快捷键 | 已实现可录制自定义键位页（命令面板、新终端、分屏、全局快速终端、打开设置，可一键恢复默认）；尚无分组可搜索的键位列表与冲突检测 |

## 暂缓项目

- 加密工作区导出、恢复预览、冲突处理和回滚。
- 应用内更新检查与发布通道。
- 独立图片查看器与系统字体枚举。
- DeepSeek Harness 的完整插件管理和协议仍在变化的高级设置。

这些项目不适合通过移植 Nebula 源码完成。后续应按本项目的 Provider、Electron IPC 和 React 组件边界独立实现，并为配置迁移和恢复流程增加专门测试。
