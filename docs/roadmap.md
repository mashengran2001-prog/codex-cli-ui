> 维护原则：所有候选都按"先看现有代码哪些能复用 → 加进 UI → 测试 → 推送"的既有流程执行；

## 四、架构性暂缓（明确不做或等上游）

- Rust + GPUI 重写：现有 Electron/Chromium 规模下收益不足（parity 文档已论证）。
- --legacy-shell 双壳：已统一为单套界面，不保留旧壳。
- 多窗口/跨显示器工作区：需要重构窗口生命周期，暂缓。

## 本轮已落地（2026-08-26，性能迭代）

- 主进程热路径：terminal-stream 预编译正则 + 无 ESC 快检，普通文本块零转义扫描（tests/terminal-stream.mjs）。
- 渲染层：数据块 250ms 聚合刷新；TerminalPane memo 化 + 稳定回调，键入命令不再重渲染全部终端 pane。
